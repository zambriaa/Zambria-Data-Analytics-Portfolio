# Zambria-Data-Analytics-Portfolio
A collection of end-to end data analytics projects using Excel, SQL, and Tableau.

Data analyst with a background in psychology, focused on turning raw data into business insights using Excel, SQL, and Tableau.

## Tools
- Excel (data cleaning, feature engineering)
- SQL (analysis, aggregation, segmentation)
- Tableau (interactive dashboards)

## Projects

### 1. Bank Customer Churn Analysis
Analyzed customer churn drivers to help reduce attrition in financial services.
- Identified high-risk customer segments
- Built churn-focused KPIs
- Created executive dashboard

### 2. Medical Insurance Cost Analysis
Analyzed healthcare cost drivers using demographic and behavioral data.
- Identified key pricing drivers
- Regression-ready dataset
- Cost segmentation insights

### 3. HR Attrition Analysis
Evaluated employee attrition patterns by role, tenure, and compensation.
- Identified turnover risk factors
- Workforce segmentation
- Actionable retention strategies

### 4. Retail Sales Performance Analysis
Analyzed product and sales trends to improve revenue performance.
- Product category analysis
- Revenue trends
- Inventory optimization insights
